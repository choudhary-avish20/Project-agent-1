Chat UI isolated Sandbox

This isolated environment allows you to develop, style, and test the Chat UI interface safely without spinning up LiveKit servers, Python scripts, or database dependencies.

How to test:
  • Type a message in the chat sidebar input on the right and press Send or press Enter.
  • A simulated agent reply will appear after a 1-second delay.
  • Use the simulation console below to inject agent messages directly.
